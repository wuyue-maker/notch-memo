# 刘海便签 · 产品方案

版本：v0.1（对应 0.1.x 开发预览）  
日期：2026-11-06  
状态：核心功能已实现；完整实机验收进行中

## 1. 产品目标

用户工作时可以随手记录和处理任务：将鼠标移到 MacBook 刘海附近，展开一张任务便签，完成操作后收起，继续使用当前软件。

产品形态拟定为独立的 macOS 常驻小工具。本文中的“置顶”指便签展开后显示在普通应用窗口上方；“固定”指用户开启固定展开，两者分别控制层级与收起行为。

## 2. 已确认需求

| 项目 | 用户选择 |
| --- | --- |
| 设备 | 2023 款 MacBook Pro，M3 Max |
| 系统 | 已核对为 macOS 27.0.1，构建号 26A434 |
| 显示器 | 主要使用内置屏，基本不使用外接屏 |
| 收起外观 | 完全隐藏，不保留纸边、标签或任务数量 |
| 唤出入口 | 鼠标移到屏幕最顶部、刘海宽度范围内的边缘，便签从顶部展开 |
| 收起模式 | 支持自动收起与固定展开切换 |
| 任务结构 | 当前便签 + 已完成的历史便签 |
| 基本操作 | 添加、编辑、勾选完成、拖动排序 |
| 完成处理 | 部分完成可恢复；全部勾完自动归档并打开下一张便签 |
| 视觉方向 | 黑色刘海连接区域 + 浅色纸质便签 |
| 全屏行为 | 全屏软件使用时仍支持悬停唤出 |
| 暂不加入 | 截止日期、提醒、优先级 |

## 3. 首版实施默认值

以下为结合上述需求制定的实施建议，可在调试中调整，无需因此阻塞第一阶段开发。

- 数据只保存在本机，不建立账号或同步服务。
- 界面使用中文，名称暂用“刘海便签”。
- 每项任务以一段纯文本记录；较长内容在显示时换行。
- 支持删除单项任务，删除后保留约 5 秒的撤销机会。
- 默认自动收起；固定状态只在本次运行中保持，重启后恢复自动收起。
- 菜单栏提供“展开便签”“收起便签”“退出”作为备用入口；顶部刘海区域仍完全隐藏。
- 不默认开启开机启动；菜单栏「开机自动启动」由用户手动勾选，记录交给系统登录项，应用自己不保存这项状态。
- 外接屏完整体验和云同步归入后续版本。
- 菜单栏“我的便签”提供进行中与已归档入口；归档按最近完成排序，条目以名称为主、日期为辅，日期放在名称后用小号浅色文字显示，不展示同日序号。
- 历史便签的任务仅供查看，可展开长任务，底部提供返回进行中便签入口。
- 标题显示便签名称，双击修改；回车或失焦保存，Esc 取消。当前与历史便签均支持改名，日期归档编号独立保留。
- 未命名便签添加第一条任务时，自动取任务开头最多 8 个中文字宽的内容作为名称；已有名称不覆盖。

## 4. 界面结构

展开后的便签水平对齐内置屏幕顶部中心，可见内容从刘海下方开始。

```text
                系统刘海
             黑色连接区域
      ╭────────────────────────╮
      │ 任务便签      固定  收起 │
      │                        │
      │ ☐ 准备项目方案       ⠿ │
      │ ☐ 整理今天的材料     ⠿ │
      │                        │
      │ ＋ 添加任务…           │
      │                        │
      │ ▸ 已完成  2            │
      ╰────────────────────────╯
```

示意图仅表达信息层次。拖动手柄初步放在右侧，勾选框放在左侧；原型中评估单手操作和误触情况后再定位置。

### 尺寸与材质起点

| 项目 | 初始建议 | 调整依据 |
| --- | --- | --- |
| 面板宽度 | 纸面 368 pt，含外侧阴影留白的窗口宽 396 pt | 阅读舒适度与屏幕占用 |
| 面板最大高度 | 内置屏可用高度的 55%，且不超过 520 pt | 避免遮挡过多工作内容 |
| 任务行高度 | 预览统一为 64 pt，展开后按全文增高 | 一行、两行预览等高，内容沿行的水平中线对齐 |
| 边角 | 下方圆角，局部轻微翘边 | 保持纸质感，避免影响阅读 |
| 材质 | 奶白底色、低对比纸纹、柔和阴影 | 浅色纸面上清楚显示任务 |

面板达到最大高度后，任务内容区域滚动，标题和添加入口保持可用。空清单展示“记下下一件要做的事”，保留添加入口。

## 5. 唤出、收起与焦点

### 触发区域

- 在刘海底缘附近及两侧设置一小段可到达的悬停热区。
- 热区位置根据实际屏幕几何信息计算，不能只依赖截图比例或固定像素。
- 实体摄像头区域不承载文字、按钮，也不作为唯一触发目标。
- 收起时只保留悬停检测；顶部不能出现可见面板，也不能用大块透明窗口拦截其他软件点击。
- 从热区移动到便签的路径应连续有效，避免刚展开又立即收起。

### 状态与规则

| 当前状态 | 触发事件 | 下一步 |
| --- | --- | --- |
| 已隐藏 | 鼠标进入热区 | 开始 300 ms 停留计时 |
| 等待展开 | 鼠标提前离开 | 取消计时，继续隐藏 |
| 等待展开 | 停留达 300 ms | 展开便签，不主动取得输入焦点 |
| 自动展开 | 鼠标离开热区与面板 | 开始 600 ms 收起计时 |
| 等待收起 | 鼠标返回 | 取消收起 |
| 自动展开 | 单击长任务文字 | 展开全文或收回两行预览，不进入编辑 |
| 自动展开 | 选择右键菜单“编辑”或点击添加入口 | 进入编辑并取得输入焦点 |
| 编辑中 | 鼠标移出 | 保持展开，不打断输入 |
| 编辑中 | 编辑结束或点击其他应用 | 保存已提交的内容，按鼠标位置和固定状态决定是否收起 |
| 拖动中 | 鼠标移出面板 | 保持展开，直到拖动结束或取消 |
| 任意展开状态 | 开启固定 | 保持展开，鼠标离开也不收起 |
| 固定展开 | 关闭固定 | 恢复自动收起规则 |
| 任意展开状态 | 点击收起 | 结束可提交的编辑、取消拖动、关闭固定并收起 |

300 ms 与 600 ms 都是初始参数，实机调试后调整。

### 中文输入与键盘

- 候选词选择期间，回车只确认输入法候选，不触发添加任务或结束编辑。
- 添加输入框中，非输入法组合状态下按回车添加非空任务，清空输入框并保持输入。
- 编辑已有任务时，回车保存，Escape 取消本次修改。
- 输入法有未提交文字时，显式收起应先完成输入或取消收起，不能直接丢失内容。
- 已展开且无编辑、拖动时，应用收到 Escape 可收起；输入法处理优先，不监听其他软件的按键。
- 面板未处于输入状态时，不抢占用户正在其他软件中使用的键盘。

## 6. 任务行为

### 添加与编辑

- 默认每条任务最多显示两行，超过两行以省略号截断显示，保存的数据仍为全文。
- 预览行高度固定为 64 pt；勾选框、文字块和手柄居中对齐，文字保持左对齐。
- 展开与编辑状态保留浅色圆角底与细描边，仅去掉左侧竖线；普通任务保留原来的悬停底色，保持文字列位置一致。
- 单击长任务展开全文，再次单击收起。展开状态按任务分别管理，仅影响本次运行的显示。
- 单击文字不再进入编辑；编辑统一通过任务的右键菜单进入。
- 编辑时自动展开原始全文，使用无额外左侧缩进的原生多行编辑器；字体、行距和左边缘与阅读状态一致。
- 编辑草稿改变时重新计算行与面板高度；回车保存、Shift＋回车换行、Escape 取消。中文选词按系统输入法处理。
- 面板高度按当前预览或展开内容计算，达到最大高度后在列表内部滚动。
- 空白文本不生成任务，新任务添加在未完成列表末尾。
- 编辑只改变文本，不改变任务身份、完成状态或顺序。
- 编辑结果仅包含空白时，不自动删除原任务；保留原内容并提示可使用删除操作。
- 任务变更及时保存；具体保存失败提示与重试行为见开发计划。

### 拖动排序

- 支持从任务文字、空白区域或右侧手柄拖动未完成任务；勾选框保留独立点击行为。
- 拖动使用整张任务卡片的纸面预览，包含文字、勾选框和手柄；原位置保留淡化占位。
- 单击文字仍展开或收起，移动超过约 4 pt 后才开始排序；单击手柄不触发展开。
- 六点手柄保留悬停变色、淡底、轻微放大和抓手光标反馈。
- 拖动时显示插入位置，其他任务平滑让位。
- 放开后保存新顺序；拖出有效区域并释放或按 Escape 时恢复原顺序。
- 接近滚动区上下边缘时允许自动滚动。
- 首版只在未完成列表内排序，不通过拖动切换完成状态。

### 完成与恢复

- 点击勾选框后，先出现弹性打勾与文字划线。
- 约 350 ms 后移入“已完成”，期间允许再次点击取消完成；快速连续操作以最终状态为准。
- 已完成区域默认折叠，显示数量；列表按最近完成时间优先排列。
- 恢复任务时移回未完成列表末尾，避免打乱现有排序。
- 已完成任务仍保留在本机，不自动清空。全部任务勾完后，将整张便签归档并创建新的空白当前便签。

### 删除与撤销

- 删除入口只放在任务的右键菜单中，支持删除未完成及已完成任务；悬停时不显示行内删除按钮。
- 删除单项任务后，在便签底部显示“已删除 · 撤销”，约 5 秒后关闭。
- 首版连续删除时，撤销入口恢复当前倒计时内的这一批任务，按原有分组和相对顺序放回。
- 退出或重启后不保留临时撤销机会；这一规则需在真实操作中保持清楚可理解。

## 7. 动效设计

| 操作 | 参考 | 首版目标 |
| --- | --- | --- |
| 展开和收起 | Sticker Peel | 从顶部舒展、回收，有轻微纸张弯曲和阻尼 |
| 悬停边角 | Sticker Peel | 小幅翘角，不遮挡文字或缩小按钮点击范围 |
| 勾选完成 | Spring Check | 勾选框、勾号、划线保持连贯的弹性反馈 |
| 删除任务 | Paper Crumple | 尝试局部纸条收拢效果，验证后决定复杂度 |

动效参考链接：[Sticker Peel](https://www.reactbits.dev/animations/sticker-peel)、[Spring Check](https://reactbits.dev/c/micro/spring-check)、[Paper Crumple](https://www.reactbits.dev/micro/paper-crumple)。这些链接是效果参考，不表示已经集成对应组件。

纸张揉皱的自然程度需要原型验证。首版若复杂揉纸影响操作流畅度，先交付轻量折叠消失，并明确记录效果差异。勾选完成只做完成反馈，揉纸用于删除。

- 动画不能阻塞继续输入、取消完成或撤销删除。
- 快速进入、离开热区时，以最终交互状态为准，取消过时动画和计时器。
- 收起时停止纸张动画；减少动态效果开启时使用短淡入淡出。
- 无交互时不持续播放装饰动画。

## 8. 全屏与屏幕变化

- 全屏唤出是核心验收项，需用原生全屏软件验证，不能用普通窗口置顶代替。
- 全屏状态下仍保留悬停入口；顶部菜单栏出现时，应检查是否与热区冲突。
- 唤出与编辑不应主动使当前全屏应用退出全屏或切换到其他桌面。
- 锁屏时隐藏便签；解锁后恢复悬停能力，不主动展开任务内容。
- 睡眠唤醒、分辨率或缩放变化后，重新计算入口与面板位置。
- 偶尔连接外接屏时，首版仍优先内置屏；合盖后内置屏不可用时，先通过菜单栏打开备用普通面板。
- 不将登录界面、系统安全界面或所有类型的系统覆盖层都纳入“置顶”承诺。

## 9. 首版完成标准

首版完成标准以[开发计划的验收清单](开发计划.md#6-首版验收清单)为准。本文描述目标行为；当前实现与实测范围见[验证记录](验证记录.md)。全部完成的揉纸已改为本地网格折叠加 Metal 渲染的 3D 纸张近似，但尚未复刻参考组件的任意边缘揭起与可交互揉纸。
