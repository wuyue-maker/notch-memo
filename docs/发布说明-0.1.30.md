# 刘海便签 0.1.30

首个可安装的预览版本（Apple Silicon / arm64）。一个驻留在 MacBook 刘海里的任务便签，数据只保存在本机。

## 安装

1. 下载 `NotchMemo-0.1.30.dmg`。
2. 双击打开，把「刘海便签」拖进「应用程序」。
3. **首次打开**：在「应用程序」里右键点「刘海便签」→「打开」，在系统提示中再点一次「打开」。

本版本使用本机临时签名、未做 Apple 公证，所以第一次不能直接双击。安装包内附有 PDF 版《安装与使用》。如果仍被拦截：

```sh
xattr -dr com.apple.quarantine /Applications/刘海便签.app
```

## 本版内容

- 鼠标靠近刘海 0.3 秒展开、移开 0.6 秒收起；可固定展开。
- 添加、编辑、勾选、恢复、删除撤销、按住右侧六点手柄拖动排序。
- 全部任务完成后：纸面冻结、网格折叠、Metal 渲染揉纸动画，归档并打开新便签。
- 菜单栏「我的便签」切换进行中便签、查看已归档便签。
- 菜单栏「开机自动启动」：登录时自动打开，随时可取消。
- 全屏与多个 Spaces 可唤出；睡眠/锁屏停止轮询；遵循「减少动态效果」。
- 本地原子写入并保留上一版备份，无账号、无网络请求。

## 校验

- 文件：`NotchMemo-0.1.30.dmg`
- SHA-256：打包后填写（`zsh scripts/package-dmg.sh` 会打印）

## 已知限制

- 面向 Apple Silicon（arm64）与 macOS 14+；只针对带刘海的 MacBook 优化；无刘海屏幕/外接屏上热区在屏幕顶部中央。
- 暂不含 iCloud 同步、多设备同步。
- 0.1.x 预览版，数据格式如有调整会保留备份与迁移。
