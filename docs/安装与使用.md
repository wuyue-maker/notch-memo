# 刘海便签 · 安装与使用

版本 0.1.30 · 需要 macOS 14 或更高

一个驻留在 MacBook 刘海里的任务便签：平时完全隐藏，鼠标靠近屏幕顶部即刻展开；记任务、勾完成、拖排序，全部完成后纸面揉成纸团归档。

## 1. 安装

1. 双击打开安装包 `NotchMemo-0.1.30.dmg`。
2. 把「刘海便签」拖进「应用程序」文件夹，然后推出磁盘映像。

## 2. 首次打开

- 本版本使用本机临时签名，未经过 Apple 公证。首次请到「应用程序」里右键点「刘海便签」→「打开」，在系统提示中再点一次「打开」。之后可以直接双击。
- 如果右键菜单里没有「打开」，到「系统设置 → 隐私与安全性」点「仍要打开」；也可以在「终端」执行下面的命令后再打开：

  ```sh
  xattr -dr com.apple.quarantine /Applications/刘海便签.app
  ```

## 3. 日常使用

- 启动后没有 Dock 图标，菜单栏会出现清单图标。
- 把鼠标移到屏幕最顶部、刘海下沿附近，停留约 0.3 秒，便签展开；鼠标移开后自动收起。
- 在底部输入框输入任务，按回车添加；点左侧圆圈完成任务，点任务文字可展开全文。
- 按住任务右侧的六点手柄拖动可以调整顺序；只在这个手柄上才能拖动。
- 点顶部图钉可以固定展开；点「收起」或按 Esc 收起。
- 全部任务勾完后，纸面会揉成纸团归档，并自动打开下一张空白便签。
- 菜单栏「我的便签」可以切换进行中的便签、查看已归档便签。

## 4. 开机自动启动

- 菜单栏清单图标 →「开机自动启动」，勾选后登录时自动打开刘海便签；取消勾选即恢复手动启动。
- 请先把「刘海便签」拖进「应用程序」再开启。从磁盘映像里直接运行、或系统临时隔离副本时，菜单会提示不可用。
- 若菜单项显示为横杠、并提示等待允许，到「系统设置 → 通用 → 登录项与扩展」打开刘海便签即可。
- 关闭开机启动、或删除应用后，系统会自动清掉这条登录项，不会留下无效记录。

## 5. 快捷键

| 快捷键 | 作用 |
| --- | --- |
| ⌘N | 新建便签 |
| Esc | 收起便签 |
| ⌘Q | 退出刘海便签 |
| ⌘Z / ⇧⌘Z | 编辑文字时撤销 / 重做 |

## 6. 数据与备份

任务只保存在本机，不需要登录，也不会上传网络：

```
~/Library/Application Support/NotchMemo/tasks.json
```

菜单栏 →「打开数据文件夹」可以直接查看；每次保存都会保留上一版 `tasks.backup.json`。

## 7. 卸载

- 从菜单栏退出便签，删除「应用程序」里的刘海便签即可。
- 如果还要清空任务，删除上面提到的 NotchMemo 数据文件夹。

## 8. 系统要求与已知限制

- 需要 macOS 14 或更高版本（Apple Silicon / arm64）；为带刘海的 MacBook 设计，无刘海屏幕上热区位于屏幕顶部中央。
- 全屏应用和多个 Spaces 下都能唤出；合盖或只接外接屏时使用主屏幕。
- 遵循系统「减少动态效果」；纸面固定浅色以保持纸张质感。
- 当前为本机临时签名版本，未做 Apple 公证；暂不含 iCloud 同步。

更完整的说明见项目仓库的 `docs/` 目录（产品方案、开发计划、使用说明、验证记录）。
